# mephi-session-project-2026
Сессионный проект по курсу «Операционные системы семейства Unix»

# Легенда
Вы получили минимальную установку Fedora 43 без графического интерфейса. Ваша задача — подготовить её к работе в локальной сети МИФИ, настроить безопасность в соответствии с политиками и развернуть простой web-сервер для публикации модели (в будущем).
